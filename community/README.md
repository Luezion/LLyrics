# LLyrics community styles

**EN** · Styles made by players. The app reads `looks.json` and shows them in *Settings → Community*.
To share yours, open LLyrics → *Settings → Community → Publish to community*. A form opens on GitHub already filled in; just click **Create**. When the repository owner adds the **approved** label, a bot adds your style to the gallery and closes the issue.

**ES** · Estilos hechos por jugadores. La app lee `looks.json` y los muestra en *Ajustes → Comunidad*.
Para compartir el tuyo, abre LLyrics → *Ajustes → Comunidad → Publicar en la comunidad*. Se abre un formulario en GitHub ya completado; solo haz clic en **Create**. Cuando el dueño del repositorio agrega la etiqueta **approved**, un bot agrega tu estilo a la galería y cierra el issue.

**PT** · Estilos feitos pelos jogadores. O app lê o `looks.json` e mostra em *Configurações → Comunidade*.
Para compartilhar o seu, abra o LLyrics → *Configurações → Comunidade → Publicar na comunidade*. Um formulário abre no GitHub já preenchido; é só clicar em **Create**. Quando o dono do repositório adiciona o rótulo **approved**, um robô coloca seu estilo na galeria e fecha a issue.

A style code (`LLY1-…`) only holds appearance options (colours, font, animations, effects). It never includes screen position, shortcuts or language.
